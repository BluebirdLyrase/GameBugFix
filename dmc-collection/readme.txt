I add this so people can find it easily, this mod is not made by me. The mod updates quite frequently, so check the link and download the latest from this site:

https://github.com/serpentiem/ddmk

Installation instructions here:

-replace the executables from the DMC.HDC.Update.2.zip, otherwise your game will crash due to an update

-open the game at least once before installing (i suggest playing mission 1 then saving)

-copy the files on the HDC folder to your game folder
C:\Program Files (x86)\Steam\steamapps\common\Devil May Cry HD Collectio
or wherever you have it installed

-in the game (dmc3)

-open the menu with left ctrl + d

-click on actor and check the enable box
-mark absolute unit option to have styles and techniques max level
